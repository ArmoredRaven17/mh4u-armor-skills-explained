## Game Data

The skill names, the in-game skill descriptions and the skill tree ladders shown on the page are read from the
game's own text tables and executable. The values in the detailed explanations were read by the author from the
game's code and data (dumped from a personally-owned copy). Only factual values and the short in-game
descriptions are reproduced; no game files are redistributed.

Community figures (Kiranico, the Monster Hunter wikis and community damage-formula documents) were used only
to cross-check readings, not as a source.

The talisman icon under [docs/assets/icons/](docs/assets/icons/) is cut from the game's own icon sheet
